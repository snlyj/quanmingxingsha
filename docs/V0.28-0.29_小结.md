# 阶段 A、B 小结（V0.28.0 / V0.29.0）

## 阶段 A：V0.28.0（versionCode 34，提交 f256579）规则按无名杀统一
对照无名杀标准包/军争包的规则口径，只比对规则，不复制代码和素材。

| 牌/技能 | 改动 |
|---|---|
| 补给 | 出牌阶段只能对自己用，满血时不能用；濒死求援时仍可救别人（对应 tao） |
| 落雷 | 只能放进自己的判定区。判定未命中时顺延给下家；没有其他人能接时回到自己判定区（对应 shandian / addJudgeNext） |
| 浮雷 | 同落雷，只能放自己判定区（简化：一并对齐） |
| 星眠 | 保护时间改为「到本回合结束」，原来持续到下个回合开始。这是削弱 |
| 音波炮 | 对应寒冰剑，效果不变 |
| 断粮封锁 | 加距离 1 的限制 |
| 羁绊锁链 | 可选 1~2 名目标，可以选自己；可以重铸（确认栏有「重铸」按钮） |
| 合璧长枪 | 两张牌当「突击」用时，颜色、花色、点数取两张的共同值，不同就算无（简化：仍自动挑两张牌） |
| 牌堆 | 197 张（斗地主模式 203 张），共 55 种牌（不是 57 种） |

AI 同步改动：
- 落雷放置参照无名杀的判断：内奸愿意放；敌人比己方多且自己体力不危险时才放。
- 新增破僵局：第 20 轮起，体力 ≥3 时也会放落雷。
- 断粮只选距离 1 内的敌人。
- 羁绊锁链：两名敌人都没被锁就连上；自己或队友被锁就解开；否则重铸。

星眠削弱后的平衡压测（夜宫静羽胜率）：1200 局，seed 20000，旧口径用 `--xingmian-legacy` 对照，turn_cap 局不计入。

| 模式 | 旧口径 | 新口径 |
|---|---|---|
| 斗地主 | 102/163 = 62.6% | 64/176 = 36.4% |
| 单挑 | 72/101 = 71.3% | 63/101 = 62.4% |
| 身份 | 129/283 = 45.6% | 109/287 = 38.0% |

同一批 1200 局的 turn_cap 局数：
- V0.27：12 局
- V0.28 加破僵局之前：53 局
- V0.28 加破僵局之后：4 局，全部是斗地主

## 阶段 B：V0.29.0（versionCode 35，提交 c03d3cc + f03e038）美术统一（樱花校园风）
- 新增 `docs/美术规范.md`，写了调色板、牌类型边框色、描边与圆角、字体层级、按钮与面板、昼夜主题和适配检查方法。代码入口是 `scripts/art.gd`。
- 卡图：55 种牌各一张原创卡图（512px webp，无文字，同名牌共用一张），另有统一卡背。
- 牌面版式：
  - 边框按类型上色：基本=樱红，锦囊=薰衣草紫，延时锦囊=靛，装备=青绿。
  - 花色和点数在左上，牌名、类型、属性和【应变】标签在底部。
  - 手牌、出牌区、长按说明卡用的是同一套版式。
- 立绘：7 名角色重新原创绘制，保持原尺寸 825×1050 和人物位置，没有描摹。官方立绘已从工作区和 APK 中移除，但旧版本 git 历史里仍有，改写历史需要你同意。
- 背景：昼樱、祭典夜两张重新原创生成。
- UI 统一：
  - 体力改成樱花图标；
  - 浮在背景上的标题和说明统一加奶白描边（`Art.halo`），夜间也能看清；
  - 主页预览、选将卡、结算 MVP 的小框统一裁半身像（`Art.bust`）。
- 适配截图：16:9、20:9、4:3，昼夜都截了，放在 `/workspace/newproj/preview/V0.29.0_*.png`。
- 体积：卡图、立绘、背景改为有损 WebP 导入（质量 0.85），图片导入体积从约 17MB 降到 3.3MB。
- 没有使用三国杀 / 无名杀 / 十周年的任何素材。
