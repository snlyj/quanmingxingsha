# V0.26 长按说明卡与新手引导

对照：无名杀 `ui/click/index.js` 的 longpress（按住 500ms 触发、移动即取消、触发后吞掉本次点击）与 `get.nodeintro`（角色：技能全文、距离、手牌、装备、判定；卡牌：名称、类型、说明）。

## 交互
- 长按 0.4 秒弹出说明卡，松手关闭；拖动超过 14px 取消长按（拖拽出牌阈值 18px，二者不冲突）。
- 桌面端：右键弹出（再点任意处关闭，这一下不会点到下面的按钮）；鼠标停留 0.7 秒弹出（移开关闭）。
- 长按触发时向视口注入「指针移出 + 界外松开」，被按住的按钮不会发出 pressed，手牌不会被选中/拖出；手牌点击回调另有兜底判断。
- 命中测试按绘制顺序取最上层控件，被遮挡（无说明的上层控件）时不弹；点击穿透层（处理区的牌、装备栏、判定图标）也能命中。
- 说明卡为全局唯一的 CanvasLayer 节点（scripts/intro.gd，IntroPop），反复复用；本身不接收鼠标；按视口尺寸夹在屏内（16:9 / 20:9 / 4:3）。

## 覆盖来源
手牌、处理区的牌、看破链面板、装备栏、判定区图标、提问/选牌窗口里亮明的牌（暗牌不挂说明）、座位头像、自己的角色牌、技能按钮与被动技能标签、选将卡、人物图鉴卡。

## 内容
- 牌：牌名、花色点数、类型（基本牌/普通锦囊/延时锦囊/装备牌·子类）、属性、完整效果（data/cards.gd `TEXT`，按引擎实际结算撰写）、武器攻击范围、应变词条与触发条件。
- 角色：立绘、名字、体力、出处、身份（公开或你的猜测）、手牌数、攻击范围、与你的距离、连环状态、全部技能全文（主动/被动、本局发动次数）、装备区与判定区内容；斗地主地主追加「飞扬」「跋扈」。
- 关键词高亮：【牌名】、突击/闪避/补给/特饮、阶段与规则名词、伤害/弃置、回复/摸牌。

## 新手引导
- 首次进入对局显示一次「长按牌或角色可查看说明」，记录在 `user://settings.cfg`（[help] longpress_hint）。
- 主页「新手说明」页与对局顶栏「说明」按钮：怎么看说明、回合流程、身份胜负、其他模式、距离与攻击范围、牌的种类、判定、伤害濒死与属性、应变、操作提示（data/help.gd）。

## 牌面文字与设计稿的差异（以引擎实际行为为准，未改设计）
- 设计稿部分牌的描述与引擎当前实现不一致（如音波炮效果/范围）；说明文字一律按引擎实际结算撰写。
- 延时锦囊（含落雷/浮雷）在本作中只能对其他角色使用，断粮封锁无距离限制——与无名杀不同，属既有实现，本版只如实写进说明，未改规则。

## 测试
- regtest D1–D6、L1–L15：每张牌/角色/技能都有说明；高亮；三种比例四角不出屏；真实输入路径长按手牌/座位/装备/判定/技能/图鉴；长按不出牌、不发动技能、不跳页；短按仍为选中；拖动不触发长按；右键常驻与关闭；节点复用不增长；首次提示持久化；新手说明页内容。
- uiplay：随机长按手牌/座位，断言必弹出、松手关闭、手牌数与选择状态不变。
