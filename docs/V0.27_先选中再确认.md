# V0.27 先选中，再确认（对照三国杀移动版 / 无名杀 game.check + ui.click.ok）

用户反馈：「有些牌和技能，玩家只是点一下，但是没确定要打出，可是默认点一次就自动释放了」。

## 排查到的「点一下就直接结算」路径（V0.26 及之前）

| # | 路径 | 旧行为 | V0.27 |
|---|---|---|---|
| a | 出牌阶段：选中有目标的牌后点合法目标头像（`_on_seat_clicked`） | 点目标即出牌（注释写着「auto_confirm 默认开」） | 点目标 = 选中/取消该目标；「确定」才出牌 |
| b | V0.25 唯一合法目标自动预选 + 点头像 | 点头像即出牌 | 仍可预选，但必须点「确定」；点头像是取消/切换 |
| c | 多目标牌（羁绊锁链） | 点第一个目标就出牌，再弹窗问第二目标 | 可点选 1~2 名目标，「确定」后第二目标直接带入，不再追问 |
| d | 合璧长枪「长枪突击」：点目标 | 立即拼牌突击 | 点目标只选中，「确定」才突击；再点按钮退出 |
| e | 木牛流马「转运」：点目标 | 立即转交 | 同上 |
| f | 响应（闪避/看破/救援等）：点亮起的手牌 | 立即打出 | 点牌只选中上浮，「确定」才打出（打出的就是选中的那张），「不出」放弃；**超时一律按不出**，即使已选中 |
| g | 引擎选牌询问（技能代价、点亮手牌） | 点亮的手牌一点即提交 | 选中后「确定」提交 |
| h | 所有选牌/选人/选区域询问的选项按钮（pick_card / pick_target / pick_from_hand / 区域选牌 / 牌或角色作为值的 pick_option） | 点选项即提交 | 选项按钮变为可切换的「选中」态，前置「确定」按钮；「取消/只连一人」等放弃类按钮保持直接生效 |

| j | 无目标牌拖出手牌区松手 | 直接使用 | 只算选中，「确定」才使用 |

| — | 拖到合法目标头像上松手 | 直接出牌 | **保留**（唯一保留的直接结算） |
| — | 弃牌阶段多选 | 已是「确定」提交 | 保持；超时/智能选择照旧 |

## 交互细节
- 点牌：上浮选中，合法目标绿框高亮，已选目标橙框；提示条（紧贴「确定」上方）显示「请选择 1 名目标」/「对 X 使用「突击」——点「确定」出牌」。
- 无目标牌：选中后提示「使用「X」——点「确定」使用」。
- 取消：再点同一张牌、点「取消」、点空白桌面都会清空选择（包括技能选择、长枪/木牛选目标、询问中的已选项）。
- 托管开启、出牌阶段结束都会清掉未确认的选择。

## 自动确认（无名杀 auto_confirm）
- 位置：对局顶栏最右的「设置」按钮（原「说明」，新手说明移入设置面板）→「自动确认」开关。
- 默认关闭；保存在 `user://settings.cfg` 的 `[play] auto_confirm`。
- 开启后：选择「已经选够、没有其他可选」时自动提交（例：唯一目标的牌点一下即出；点亮的闪避一点即打出；多目标牌需选满两名或只有一名可选时才自动）。提交用 call_deferred，避免在按钮自身信号里释放按钮。
- 无名杀里该选项默认开启（library/index.js `auto_confirm init:true`），本作按用户要求默认关闭。

## 其他
- 阶段标题移到功能条与右侧信息胶囊之间，不再与「记牌…设置」按钮重叠。
- 引擎 `respond_with` 增加 `ui.resp_pref`：真人响应时打出选中的那张牌。
