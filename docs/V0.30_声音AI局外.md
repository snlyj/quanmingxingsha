## 2. AI（只改 AI 决策，规则不变）
- **斗地主 turn_cap 清零。** 拉锯基本都出在「森崎千夏」对「夜宫静羽」或「花宫雏」的残局：双方回复和伤害差不多，而且有人够不着对手。改动如下：
  - 星眠：第 25 轮起只在 1 血时发动；前期手里有能出的突击就不星眠。
  - 元气补给：本回合还能出突击时先出突击；第 30 轮起只在 2 血及以下时回复。
  - 补给（对自己用）：第 30 轮起只在 2 血及以下时吃，其余留着濒死时自救。
  - 樱愿：残局选回复的血线从 2 降到 1。
  - 作为代价弃牌时，留下最后一张能出的突击（参照无名杀 get.value）。
  - 目标有「防护立场」时不出黑色突击（破甲光剑、七宝利刃除外）。
  - 拆牌顺序参照无名杀过河拆桥 AI：够不着目标时先拆防御坐骑，否则防具优先于武器。
- **身份场更像人。**
  - 新增 `situation()`，参照无名杀 get.situation。内奸在主公方占优时把疑似忠臣当敌人，否则打疑似反贼，终局前不打主公。
  - 新增 `ai_target_score()`，参照 ai.basic chooseTarget：综合体力、手牌数、1 血斩杀、防具；反贼对主公有额外加权。
- **Bug 修复**：连环传导让出牌者自己阵亡后，「双生短刃」仍会让他摸 1 张，导致阵亡角色手里还有牌（dead_holds_cards）。现在阵亡后不再触发武器效果。

## 3. 局外系统（数据在 user://meta.json）
- **战绩**：最近 50 局的明细；总计、各模式、各身份的局数、胜场和胜率。
- **角色熟练度**：每局经验 = 10 + 胜利 15 + 伤害（最多 10）+ 击杀 ×5 + MVP 5。
  - 等级门槛 0 / 40 / 120 / 250 / 450 XP，对应 Lv1~5：见习 / 熟练 / 精通 / 大师 / 传说。
  - 结算页会显示本局获得的熟练度和升级。
- **成就 20 个**：
  - 局数：初次登场、常客、老玩家；
  - 胜场：初战告捷、胜利者；
  - 各身份获胜：樱下之主、忠心耿耿、揭竿而起、笑到最后、地主之威、农民翻身、单挑王；
  - 单局表现：火力全开、连斩、樱花治愈、本局 MVP、毫发无伤；
  - 收集与成长：全员集合、得心应手；
  - 教学：新手毕业。
  - 结算页会提示本局解锁的成就。
- **教学关（脚本化单挑）**：
  - 固定花宫雏（先手）对柚木铃奈（简单 AI，2 血），起手发好 星光长剑 / 突击 / 闪避 / 补给。
  - 共 5 步提示：装备 → 选突击和目标 → 确定 → 结束回合并讲解响应 → 自由练习。
  - 分出胜负就算完成，解锁「新手毕业」。
- **主页入口**：第三排改为「战绩·成就 / 教学关 / 新手说明 / 祭典夜」四个按钮。
- **测试隔离**：带命令行参数运行（自测、截图）时，数据写到 user://meta_test.json，不影响玩家存档。
