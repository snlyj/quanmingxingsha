## 布局（实战帧 f_020 / f_017 确认）

1. 对手不是"信息面板"，而是**整张竖版武将卡**环绕桌面：左 1、上 2、右 1；
   名字竖排在卡左缘，势力/身份角标在卡顶角，**体力是贴在立绘右缘的一列绿色勾玉**，
   手牌数是卡左下角的小数字徽章。
2. 自己在**右下角一张放大的武将卡**（带金红框），当前行动者有动态光效边框。
3. 自己的手牌在底部中央**扇形叠排**（互相压住一半），点选时上浮。
4. 自己的装备在左下角做成**紧凑筹码行**（图标+名字+范围数字逐行列），不占大块面积。
5. 技能是手牌区右侧上方的**胶囊按钮**（技能名即按钮），可发动时亮起。
6. 打出的牌停在桌面中央成一行；悬停/选中卡牌时，手牌上方有一条**深色说明条**
   显示这张牌/技能的规则文本。
7. 桌面背景是整幅主题画（白虎），桌面本身几乎没有"桌子"的形状，立绘卡就是座位。

## 流程与动画

1. 开局中央有金色书法大字**「战斗开始」**横幅。
2. 选牌类弹窗（看对方手牌/装备）：居中面板，顶部技能名标题，左侧目标大立绘，
   区域分「手牌」「装备」两栏（手牌以背面示人），面板下方一条**青色倒计时长条**
   不断缩短，确定/取消按钮在条下方居中。
3. 技能发动（大技能）：角色**大立绘从屏幕侧边滑出放大特写**，带能量光晕与技能名，
   停留约 1 秒再收回；小触发只有卡面闪光+技能名条。
4. 指定目标时，可选目标是**绿色亮框**，不可选的变暗（与我方现行实现一致）。
5. 元素伤害（雷杀等）是贯穿目标的**竖直光束特效**+受击抖动；伤害飘字大而醒目。
6. 回合/阶段切换有中央字卡；濒死时角色卡红光闪烁。
