# 《全明星杀》× 无名杀（noname v1.10.9）移植对照表

原则：规则层按无名杀源码的结构与判定顺序在 GDScript 里重写（重构，非逐行翻译）；
每个规则可指回源码出处。角色与美术用我们自己的，UI 用我们现有的（更精致）。

## 源码体量（实测）
- 引擎逻辑核心 noname/ 模块约 70,303 行（含 UI 约 1.5 万行）：
  library/index.js 13,357 / element/player.js 10,432 / element/content.js 8,515 /
  game/index.js 8,374 / get/index.js 4,729
- mode/identity.js 4,212 行；card/standard.js 3,630 行
- 结论：逐行翻译不可行且会把翻译错误叠加在原代码的复杂度上；
  按「事件系统 + 内容结算 + 模式流程」的结构重构，才是可验证的移植。

## 引擎结构对照（noname → 本项目 scripts/engine.gd）
- game.createEvent(name) + _status.event 事件链 → 事件 = await 协程函数 + fire(timing, ctx) 触发分发
- lib.skill[skill].trigger = {player: "phaseBegin", global: [...], source/target} → 技能注册表：
  sid → {timings: {时机名: {who, priority, filter, content}}}
- 触发时机命名照 noname：phaseBefore/phaseBegin/phaseZhunbei·Judge·Draw·Use·Discard·Jieshu
  （各含 Start/End）、damageBefore/damageBegin/damageEnd/damageAfter、useCard/dying/die 等
- 回合阶段表照 content.js phase()：['phaseZhunbei','phaseJudge','phaseDraw','phaseUse','phaseDiscard','phaseJieshu']
- 身份胜负照 mode/identity.js：主公阵营（主+忠）胜 = 反贼与内奸全灭；反贼胜 = 主公亡；
  内奸胜 = 主公最后亡且其余全灭。奖惩：杀反贼摸3、主公误杀忠臣弃光手牌与装备。
