## 廉价感的五个成因（对照我方现状）
1. **背景是纯色渐变** → 头部二游全是插画场景或带纹理的材质面（影之诗的桌面是石质纹理＋暗角＋金属饰件；BA 主界面是整幅教室插画）。
2. **面板是「白底＋单色描边」** → 人家是多层材质：金属描边＋宝石徽章＋缎带铭牌＋投影，每层都有高光。
3. **数字/状态是纯文字** → 人家做成徽章：菱形/盾形宝石里嵌数字，带描边和高光点。
4. **卡牌是文字卡** → 人家卡面有插画窗、色带、花色角标、类型标签，是「设计过的卡」不是「贴了字的框」。
5. **没有字体设计** → 标题带投影/描边、英文小字作装饰（ALL STAR KILL 式）、伤害数字是描边大字。

## 落地工艺（Godot 代码可实现，已在样本 D/E 验证）
- 插画背景：AI 生成场景图（assets/bg/bg_blossom_day.webp 樱庭昼、bg_festival_night.webp 祭典夜，2048×1152），全屏 COVERED 铺放；注意新资源要先跑一次 `--import`，且 TextureRect 必须 add_child 后再设 position/size（先设尺寸会被贴图尺寸顶掉——本项目已两次踩坑）。
- 座位卡：外层金框 Panel＋白衬＋立绘＋细白内描边；左上身份宝石（圆＋白边＋投影＋高光点）；右缘粉色体力点（带高光）；底部缎带铭牌（微旋转、溢出卡沿）压名字；手牌数做成深色小徽章。
- 手牌/展示牌：顶部色带放花色点数、中央大字带浅色光晕圆、底部牌名＋类型小字。
- 按钮：胶囊＋上半高光层＋白描边＋投影；主按钮金色。
- 标题：主字＋投影副本＋英文间距小字＋金色短线；伤害飘字白描边大红字（样本里为静态示意）。
