# V0.25 对局体验优化清单（对照无名杀 / 十周年UI / 手杀）

调研日期：2026-11-16。参考：
- 无名杀本体（ref/noname，本次新增稀疏检出 ui/click、ui/index、game/check、layout/mobile）：
  - `game/check.js`：选牌 / 选目标的统一判定，可选项加 `selectable`，不可选不加（界面置灰），`selected` 上浮；`confirm()` 在选择完整时生成「确定 / 取消」。
  - `ui/click/index.js`：`cardtouchstart / cardtouchmove` 拖拽出牌（拖出即选中，拖过角色即选为目标，`enable_touchdragline` 画虚线指示线，`windowtouchend` 松手时 `game.check()` 通过则 `ui.click.ok()`，否则复原）。
  - `ui/index.js updatehl()`：手牌重叠排布，间距 `min(112, (容器宽-128)/(n-1))`，小于 32 才出横向滚动；选中牌 `translateY(-20px)` 上浮。
  - `library/index.js` 配置 `auto_confirm`（默认开）：「候选目标只有 1 个时，点击目标后无需再点确认」。
  - `player.js`：`$throw`（牌飞入处理区）、`$draw`（牌堆飞入）、`$damage`（受击位移/缩放）、`$damagepop`（伤害飘字逐个排队）、`$recover`（回复光效）、`$die / $dieflip`（阵亡翻倒）、`$skill / $fullscreenpop`（技能名大字）。
- 十周年UI（GitHub diandian157/decadeUI，GPLv3，只学做法不拷代码/素材）：自动选择、幻影出牌、单独装备栏、出牌提示卡牌映射、动皮出框（gongji/teshu）、手牌折叠、本体拖拽兼容。
- 已有笔记：docs/手杀对局观摩笔记.md、docs/UI精致化调研笔记.md、docs/优化清单_对标改版无名杀.md。

优先级：P0 = 直接影响手感/易用（第 1 批），P1 = 演出完整度（第 2、3 批），P2 = 锦上添花（第 4 批）。
「现状」为 V0.24.0 代码实况。

## 一、出牌手感（第 1 批，P0）

| # | 项目 | 参考 | 现状 | 做法 |
|---|---|---|---|---|
| 1.1 | 手牌重叠扇形、多牌自动压缩 | updatehl() | HBox 固定 -62 重叠 + 横向滚动条，手牌多时要拖动滚动，每次刷新整排重建节点 | 自绘手牌层：按可用宽度算间距（不够就压缩，最小 44px），轻微扇形（±1.2°/张，最多 ±7°）+ 弧形下沉；节点按牌复用，位置变化才建 Tween |
| 1.2 | 点选上浮 | check.js selected | 选中后 offset_top -24，但点击即出牌 | 点一下选中上浮 36px 并发光，再点同一张取消；切换选中直接换 |
| 1.3 | 拖拽出牌 + 吸附 + 回弹 | cardtouchmove / windowtouchend | 无（拖动只会滚动手牌） | 按住可用牌上拖 > 18px 进入拖拽：牌跟手、画指示线；拖到合法目标头像 40px 内吸附（牌向头像中心靠拢、头像放大）；松手在合法目标上 = 对其出牌，无目标牌拖出手牌区 = 使用；否则 TRANS_BACK 回弹原位 |
| 1.4 | 不能用的牌置灰 | selectable | 已有（modulate 0.78），对比度弱 | 置灰加深并去饱和；响应时只有可打出的牌亮起 |
| 1.5 | 合法目标高亮 / 非法灰掉 | game.check target | 已有绿框 + 半透明 | 保留；增加目标呼吸光圈；唯一候选自动预选（auto_confirm） |
| 1.6 | 确定 / 取消 / 结束出牌按钮 | ui.create.confirm | 选目标时提示框里一个「取消」，「结束出牌」在右下，非指向牌点击即出 | 手牌上方居中一条操作栏：确定（金）/ 取消（白）/ 结束（粉），按选择状态启用/禁用；非指向牌选中后点「确定」或拖出手牌区使用（再点同一张 = 取消选中，同无名杀）；点目标即确认（auto_confirm） |
| 1.7 | 多选牌计数（弃牌阶段） | selectCard 范围 + 提示 | 弃牌一张一张弹选项按钮 | 弃牌阶段一次在手牌里点选 N 张，提示「请弃置 N 张（已选 x/N）」，凑满才能确定；另有「智能选择」 |

| # | 项目 | 参考 | 现状 | 做法 |

- 7.3 点空白桌面：有选中牌时先取消选择，否则跳过当前等待（AI 出牌间隔等）；特效层 / 处理区所有节点强制点击穿透。
