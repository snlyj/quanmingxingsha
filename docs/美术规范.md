# 全明星杀 美术规范（V0.29.0 起）

风格：**二次元校园 / 樱花**。明亮、柔和、粗描边赛璐璐。全部素材为本项目原创生成，**不使用三国杀 / 无名杀 / 十周年任何素材**（立绘、卡图、卡背、框、图标、字体均不引用）。
代码入口：`game/scripts/art.gd`（`const Art = preload("res://scripts/art.gd")`）。

## 3. 卡牌版式（基准 172×236，按宽度等比缩放）
- 外框：类型色 StyleBox，圆角 14，边宽 4（选中时换深樱/金色高亮）。
- 卡图：(6,6) 160×168，COVERED 裁切，**无文字**；同名牌共用一张 512px webp（`assets/cards/<slug>.webp`）。
- 左上：奶白圆角小牌（圆角 8），花色符号 + 点数，红/黑花色色。
- 底部名牌：类型色色块，牌名白字粗体；第二行“类型 · 属性”；右上角属性小签（火/雷/冰）；【应变】标签金色小字。
- 卡背：`assets/cards/back.webp`（樱花纹章 + 梅紫底），所有背面牌、牌堆、展示区背面统一使用。
- 卡图生成提示词模板：`One bold central subject …, crisp dark plum outlines, cel shading, anime school cherry-blossom style, background gradient <类型渐变>, no text`。

## 6. 按钮与面板
- 主按钮：樱粉实心 + 白字（如“开始对战”“再来一局”）；次按钮：白 88% 底 + 金边 + 深樱字（如“返回主页”“退出”）。
- 危险/认输等功能条按钮与次按钮同款，只靠文字区分，避免满屏红色。
- 弹窗：奶白底 95%，金边，圆角 24，背后 40% 遮罩；结算页 MVP 区用金色星标。
- 体力：樱花图标 `assets/ui/hp_petal.png`（满）/`hp_petal_empty.png`（损失），25px；文本处用 ♥。
- 立绘小框统一用 `Art.bust(path, 宽高比)` 裁半身（主页预览、选将卡、MVP），座位/人物图鉴用全身。

## 8. 适配检查
大厅、选将和牌桌检查 16:9 (1920×1080)、20:9 (2400×1080)、4:3 (1440×1080) 的昼夜主题。身份场使用固定对局截图验收自己的出牌阶段、选目标、响应、濒死和结算。手牌预设覆盖 4、10、25 张。

~~~bash
bash 工具脚本/shots.sh 1920x1080 day home draft review_play review_target review_respond review_dying review_result review_hand10 review_hand25
SHOT_EXTRA=--night bash 工具脚本/shots.sh 2400x1080 night home review_play review_target review_respond review_dying review_result review_hand10 review_hand25
~~~

Android 真机上用左右横屏验证刘海安全区与常用操作约 48 dp 的有效触控区。测试点按、长按、横滑、向上拖牌、无效松手、连点和切后台。低端机连续对局观察帧时间是否稳定在 30 fps 的约 33 ms 帧预算内，记录点击到首个视觉反馈的延迟。邀请新玩家在无口头说明的情况下完成一次出牌和一次响应，记录他们找不到的位置和提示。
